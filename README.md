# listendeck

A minimal suite of social music utilities, built as the independent successor to BubbleFM following the discontinuation of the free Last.fm API.

## Overview

- **Charts** (`/charts`) — Weekly and monthly listening reports via public ListenBrainz handles.
- **Match** (`/match`) — Profile compatibility comparison between two ListenBrainz users.
- **Lyrics** (`/lyrics`) — Track lyrics viewer and shareable cards.
- **Cards** (`/cards`) — Quick visual story cards from track metadata.

## APIs

- **ListenBrainz** — Scrobble history and user stats
- **LRCLIB** — Synced and plain lyrics
- **Deezer** — Track metadata and album artwork
