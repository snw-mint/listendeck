Credits & Architecture.

Open data sources, client-side privacy, and open-source licensing behind listendeck.

01

Data Sources & APIs.

  • ListenBrainz (MetaBrainz Foundation) →

    Listening history, user playback counts, and artist/track comparison data for Charts and Match.

  • LRCLIB →

    Synchronized and plain song lyrics lookup for the Lyrics card studio.

  • Deezer Public API →

    Artist portraits, album covers, and track metadata resolution.

  • Cover Art Archive →

    Fallback release artwork sourced from MusicBrainz identifiers.

02

Privacy & Local Storage.

listendeck runs 100% in your browser as a static web application. There is no backend server, user database, or account system—no passwords or personal credentials are ever collected. Temporary API responses and recent username shortcuts are stored locally in your browser's localStorage and sessionStorage purely to improve loading speed and reduce external API requests.

Anonymous, cookieless analytics are collected via Umami strictly to measure aggregate feature usage (such as selected timeframes and export styles), without tracking personal identities, IP histories, or searched usernames.

Because this is an independent, community-driven project provided "as is" without warranties, continuous uptime or uninterrupted quality cannot be guaranteed. All features rely directly on external public APIs (such as ListenBrainz, LRCLIB, and Deezer); if any of these third-party services experience downtime, rate limits, or breaking changes, parts of listendeck may become temporarily unavailable.

04

Third-Party Assets & Trademarks.

Album artwork, artist portraits, and song lyrics are retrieved on demand directly by your browser from their respective public APIs and are never hosted or stored on our servers (temporary local browser caching is used solely to improve responsiveness and respect API rate limits).

Streaming service logos (such as Spotify, Apple Music, YouTube Music, Deezer, and Last.fm) are disabled by default and provided strictly as optional labels for users to indicate their preferred listening platform.
